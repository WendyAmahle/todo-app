# Third-Party Code

The application uses the following third-party packages.

## Runtime Dependencies

### Next.js 16.2.12

Next.js is the web framework used to build the application. It provides the application structure, page routing and API routes.

### React 19.2.4

React is used to build the interactive user interface and manage UI state such as task information, editing and sorting.

### React DOM 19.2.4

React DOM renders the React interface in the browser.

### SQLite3 6.0.1

SQLite3 provides access to the SQLite database used for persistent task storage. It was selected because the assignment requires SQLite and the application needs local persistence without requiring a separate database server.

## Development Dependencies

### TypeScript 5

TypeScript provides static type checking for the application's code.

### Vitest 4.1.10

Vitest is used to run the automated database behaviour tests.

### ESLint 9

ESLint is used to identify potential code-quality and programming errors.

### eslint-config-next 16.2.12

This provides the ESLint configuration intended for Next.js projects.

### Tailwind CSS 4

Tailwind CSS is included for styling the application.

### @tailwindcss/postcss 4

This provides the PostCSS integration used by Tailwind CSS.

### @types/node

Provides TypeScript definitions for Node.js APIs.

### @types/react

Provides TypeScript definitions for React.

### @types/react-dom

Provides TypeScript definitions for React DOM.
